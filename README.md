When the program is initially launched, you will get 4 buttons -
A "Select Texture Folder" button - SELECT THE "texture" FOLDER FROM THE PACK YOU WANT TO CONVERT.
A "Select Output Folder" button - Select the folder you want to be an output for the pack/
A drop down menu to set the resolution.
A checkbox to set whether the version of the texture pack is 1.14 or newer, or older than 1.14.
And last - a build button. Upon setting up the aforementioned buttons above, press it and a Pack.zip folder will appear in the selected output folder.
